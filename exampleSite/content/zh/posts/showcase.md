本页专注于 Markdown 语法可以实现的效果。在这里你可以看到各个组件在结构与样式上是如何渲染为 HTML 的。

# 标题的使用

标题是用于章节标题的大号文字，大小从 1 到 5（由大到小）各不相同，如下所示：

# 一级标题

## 二级标题

### 三级标题

#### 四级标题

###### 五级标题

### 自定义锚点

标题会获得一个悬停时显示的自链接，也可以显式指定锚点 id：

## 带自定义锚点的标题 {#custom-anchor}

跳转到它：[前往自定义锚点](#custom-anchor)。

## 段落

段落是承载标准页面内容的容器。其字体定义在 CSS 中，并可按[自定义](/posts/customization)一文中提到的方式配置。

## 列表

### 有序列表

1. 第一项
2. 第二项  
   2.1. 第一个嵌套项
3. 第三项

### 无序列表

- 无序项
- 另一个项
- 还有一个

### 任务列表

- [x] 渲染复选框
- [ ] 按主题配色着色

## 表格

| 编号 | 键    |  数据   |
| :--- | :---- | :-----: |
| 1    | 键 1  | 值 1    |
| 2    | 键 2  | 值 2    |
| 3    | 键 3  | 值 3    |

## 代码

### 行内代码

行内代码长这样：`inline-code-example`。通过将文本包裹在反引号（`）中定义，会以不同的颜色和等宽字体显示。

### 代码块

代码块支持多种语言的语法高亮。

```yaml
yaml:
  syntax:
    highlighted:
      so: cool!
```

## 媒体

图片等媒体可以使用 `![alt](/images/file.png)` 语法插入

## 脚注

脚注渲染在页面末尾，并提供跳回正文的链接。[^1]

[^1]: 这是脚注的内容，同样支持 **Markdown** 语法。

## 数学公式

行内公式如 \(\alpha + \beta\) 与块级公式均由 KaTeX 渲染：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
